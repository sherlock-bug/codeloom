## 测试用例问题（非代码 bug）

以下测试用例预期与实际实现不匹配，需调整：
1. CLI-5b, CLI-16b: codeloom 对错误路径/RGraceful 处理，非错误退出（design decision）
2. CLI-1, CLI-29: header-only 库（spdlog, flatbuffers）0 symbols 是预期行为（codeloom 只解析 .cpp TU）
3. CLI-22: `__builtin__` 分支为 auto-generated，不可被 --branch clean
4. MCP-07: 查询 "Status" kind=enum 可能无匹配（需改用确切 enum 名）
